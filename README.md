# 🏠 Видеонаблюдение — Умный Дом

Современное адаптивное PWA-приложение для системы видеонаблюдения с красивым интерфейсом для мобильных и десктопных устройств.

![Version](https://img.shields.io/badge/version-1.0.0-purple)
![PWA](https://img.shields.io/badge/PWA-ready-brightgreen)
![Responsive](https://img.shields.io/badge/responsive-mobile%20%26%20desktop-blue)

## ✨ Возможности

- 📹 **Просмотр камер** — сетка или список, реальные кадры с сервера
- 🔔 **События** — детекция людей, машин, животных с видео
- 📁 **Архив** — просмотр записей по дате и камере
- 👥 **Пользователи** — управление доступом
- ⚙️ **Настройки** — Telegram, VK, Алиса уведомления
- 📱 **PWA** — установка на главный экран телефона
- 🎨 **Адаптивный дизайн** — отлично работает на мобильных и десктопе
- 💻 **Десктопная версия** — боковая навигация, большие карточки
- 📱 **Мобильная версия** — нижняя навигация, компактный интерфейс

## 🖥️ Адаптивный дизайн

## 🔌 Подключение к серверу

Приложение подключается к вашему `cctv_server.py` на порту **8080**.

### Настройка CORS

Добавьте в `cctv_server.py`:

```python
@app.after_request
def add_cors_headers(response):
    response.headers['Access-Control-Allow-Origin'] = '*'
    response.headers['Access-Control-Allow-Credentials'] = 'true'
    response.headers['Access-Control-Allow-Headers'] = 'Content-Type'
    response.headers['Access-Control-Allow-Methods'] = 'GET, POST, OPTIONS'
    return response
```

### Изменение адреса сервера

Отредактируйте `src/api.ts`:

```typescript
export const API_BASE = 'http://ваш-сервер:8080';
```
